# Frontends

TypeScript frontends for Agent Saddlery — TUI ([Ink](https://term.ink/)), Web (React), desktop
([Tauri](https://tauri.app/)), and IDE (VS Code) — talking to the headless Python engine in
[`../backend/`](../backend/) over the shared [AG-UI](https://docs.ag-ui.com/introduction) protocol.

Empty for now: the first frontend (Ink TUI) lands at **Phase 0.3**. This directory establishes the
`backend/` + `frontend/` sibling convention ratified in
[ADR-0001](../docs/adr/0001-repository-layout.md).
